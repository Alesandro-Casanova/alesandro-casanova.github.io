    ¿Qué pasa cuando la caja reintenta?
    Si la respuesta se pierde después de registrar la venta, la caja puede enviar otra vez la misma solicitud. La API reconoce la clave y los artículos, y devuelve el comprobante original. El stock baja una sola vez.
    Probá también «Otra compra con la última clave» para ver cómo se rechaza una compra distinta con esa clave. Con «Stock insuficiente» podés comprobar que se conserva el inventario completo, incluso cuando sí alcanzaba para el primer artículo.
