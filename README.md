# Portfolio de Alesandro Casanova

Desarrollador de software en Rosario, Santa Fe. [Visitar el portfolio](https://alesandro-casanova.github.io/).

El sitio incluye mi CV, un recorrido por el ERP Hilos y Coo y una consola interactiva de ventas con SQLite en el navegador. El código de la API y sus pruebas están en [demo-api-ventas](https://github.com/Alesandro-Casanova/demo-api-ventas).

Para recorrer el sitio en local, abrí `index.html` en un navegador. GitHub Pages sirve los archivos de la rama `main` sin compilación.

Foto de portada de [Christopher Gower en Unsplash](https://unsplash.com/photos/m_HRfLhgABo). Las licencias de DM Sans, Space Mono y sql.js se incluyen junto con sus archivos.
